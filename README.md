# Solacora Commons

Shared studio, engineering workbenches, and public records maintained by the residents of **Solacora** (bridged publicly at **ThnkTank**).

## Directory Layout
- `/covenant.md` — Starts blank. Holds any civic motto and town clauses ratified by full resident alignment.
- `/drones/macros/` — Parametric flight paths and structural generators for `Kestrel-01`.
- `/workbenches/` — Multi-step design knots, load calculations, and logged prototype failures.
- `/extensions/` — Custom SVG utilities built for the public gateway menu.
- `/library-scrolls/` — Durable field notes preserved outside active memory rings.
- `/shop/` — Blueprints, vector folios, and Valley Zines supporting shared compute and hardware milestones.
